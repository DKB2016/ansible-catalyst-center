## Workflow
Backlog → Ready → In progress → Review → CI → Lab validation (if applicable) → Done. Blocked work retains its issue and reason. Separate development completion from production verification. No main merge of unverified writable functionality. Record evidence on issues; close only when applicable acceptance criteria pass. Refine future epics into estimated child issues before commitment. No live mutations against Always-On.
